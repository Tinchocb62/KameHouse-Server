# Regla de Comunicación: Diagnóstico y Plan de Acción Obligatorio

Cada vez que el usuario indique que algo "está mal", "se ve mal", "no está bien", "revisa esto", o señale cualquier inconsistencia visual o de código:

1. **Diagnóstico Técnico**: Explicar primero con total claridad qué está causando el problema.
2. **Plan de Acción Detallado**: Detallar qué cambios específicos se planean realizar para solucionarlo.
